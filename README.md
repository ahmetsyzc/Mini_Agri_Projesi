# 🏔️ Atlas Ağrı Projesi

Atlas Ağrı, C# Windows Forms ve Microsoft SQL Server kullanılarak geliştirilmiş bir masaüstü uygulamasıdır.

Uygulama; Ağrı ili hakkında çeşitli bilgileri kullanıcı dostu ve etkileşimli bir masaüstü arayüzü üzerinden sunmak amacıyla geliştirilmiştir. İlçeler, nüfus bilgileri, yöresel yemekler, tarihçe ve gezilecek yerler gibi farklı bölümler içermektedir.

## 🚀 Özellikler

- Ağrı ve ilçeleri hakkında bilgiler
- İlçelere ait nüfus bilgilerinin görüntülenmesi
- Nüfus verilerinin grafiklerle görselleştirilmesi
- Yöresel yemeklerin tanıtılması
- Ağrı'nın tarihçesi hakkında bilgiler
- Gezilecek yerlerin tanıtılması
- Seçilen ilçeye göre dinamik görsel gösterimi
- Gece ve gündüz arayüz modları
- Birden fazla formdan oluşan Windows Forms yapısı
- SQL Server veritabanı entegrasyonu

## 🛠️ Kullanılan Teknolojiler

- C#
- .NET Framework
- Windows Forms
- ADO.NET
- Microsoft SQL Server
- Visual Studio

## 📊 Veri ve Görselleştirme

Uygulamadaki nüfus bilgileri SQL Server veritabanından ADO.NET kullanılarak alınmaktadır.

Verilerin kullanıcıya sunulması ve görselleştirilmesi için çeşitli Windows Forms bileşenlerinden yararlanılmıştır:

- Chart
- ProgressBar
- TreeView
- ListView
- PictureBox

Bu bileşenler sayesinde Ağrı ve ilçelerine ait nüfus bilgileri, görseller ve diğer veriler farklı biçimlerde kullanıcıya sunulmaktadır.

## 🖥️ Uygulama Yapısı

Proje, farklı içerikleri birbirinden ayırmak amacıyla birden fazla Windows Form kullanılarak geliştirilmiştir.

Uygulamada bulunan temel bölümler:

- İlçeler
- Nüfus Bilgileri
- Yemekler
- Tarihçe
- Gezilecek Yerler
- Hakkımızda

Ana ekran üzerinden bu bölümlere erişilebilmekte ve her bölüm kendi formu içerisinde görüntülenmektedir.

## 📚 Proje Hakkında

Bu proje, C# ile masaüstü uygulama geliştirme sürecinde edindiğim bilgileri pratiğe dökmek amacıyla geliştirdiğim projelerden biridir.

Proje geliştirme sürecinde Windows Forms kullanımı, birden fazla form arasında geçiş, SQL Server veritabanı bağlantısı, ADO.NET ile veri işlemleri, Windows Forms bileşenlerinin kullanımı ve temel veri görselleştirme konularında pratik yapma fırsatı buldum.

## 📸 Ekran Görüntüleri

Projenin kullanıcı arayüzüne ait ekran görüntüleri bu bölümde paylaşılacaktır.
